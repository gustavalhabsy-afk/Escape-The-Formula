DUNGEON

Taklukkan dungeon dengan kekuatan ilmu matematika!

📚 Matematika Kelas X · Persamaan

Gunakan WASD / Arrow Keys untuk bergerak · SPACE untuk interaksi

📖 CARA BERMAIN

  • Gerak: Gunakan WASD atau tombol panah untuk menjelajahi dungeon.
  • Interaksi: Dekati monster/boss dan tekan SPACE atau langsung tabrak mereka untuk memulai pertarungan.
  • Pertarungan: Jawab soal Matematika pilihan ganda. Benar = serang musuh, Salah = kehilangan 1 HP.
  • Dialog: Setiap monster akan bicara dulu sebelum pertarungan dimulai.
  • Tujuan: Kalahkan 3 monster penjaga untuk membuka ruang Boss, lalu kalahkan Boss untuk naik lantai.
  • Topik: Lantai 1 = PLSV, Lantai 2 = SPLDV, Lantai 3 = Persamaan Kuadrat.
  • HP: Kamu punya 3 HP. Jika HP habis, game berakhir.

ℹ️ TENTANG GAME

Escape The Formula adalah media pembelajaran digital interaktif untuk siswa kelas 10 SMA/MA. Game ini menggabungkan eksplorasi dungeon bergaya RPG dengan soal pilihan ganda Matematika.

Topik yang dibahas meliputi Persamaan Linear Satu Variabel (PLSV), Sistem Persamaan Linear Dua Variabel (SPLDV), dan Persamaan Kuadrat — sesuai kurikulum Merdeka kelas 10.

Setiap pertarungan memberikan umpan balik langsung beserta pembahasan singkat, sehingga siswa dapat belajar dari kesalahan mereka.

🎓 Dibuat sebagai media pembelajaran inovatif
